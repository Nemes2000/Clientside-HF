# Clientsite-HF

The project was made as a home work. The project developed a base Angular web application.
The specification was the following:

**GAME OF THRONES**
_Create an app that showcases the editions and characters of the popular "Game of Thrones" book series.
The app should be built using the Ice and Fire API (https://anapioficeandfire.com/). The finished app
must be able to navigate the world of Game of Thrones in an interactive and user-friendly way; that is,
the app should be able to list books, characters, and families, display them concisely (e.g.,
in search results), and display all their data on a detailed page/interface. The
data for related entities (e.g., a character’s relatives) should be easily accessible and navigable._
